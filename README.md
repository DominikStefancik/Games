## List of games (grouped by a language)

### Javascript/Typescript
* [Breakout](breakout-with-javascript) - classical game Breakout implemented with vanilla Javascript
* [Chess](chess-with-react-and-rxjs) - Chess game implemented with React and Rxjs
* [Duck Hunt](duck-hunt-with-typescript-and-kaplay) - game based on the classical Nintendo game with the same name implemented with Kaplay
* [Escape the Factory](escape-the-factory-metroidvania-with-typescript-and-kaplay) - game based on Metroidvania style games implemented with Kaplay
* [Fighting Game](fighting-game-with-typescript-and-kaplay) - fighting game in the style of Mortal Kombat implemented with Kaplay
* [Sonic Runner](sonic-runner-with-javascript-and-kaplay) - runner game based on the famous game Sonic the Hedgedog implemented with Kaplay
* [Super Mango](super-mango-platformer-with-typescript-and-kaplay) - game based on the classic Nintendo game Super Mario Bros implemented with Kaplay
* [Tetris](tetris-with-react) - classical game Tetris implemented with React
* [Tic Tac Toe](tic-tac-toe-with-react) - classical game Tic Tac Toe implemented with React

### Rust
* [Breakout](breakout-with-rust-and-bevy) - classical game Breakout implemented with Bevy
* [Cat volleyball](cat-volleyball-with-rust-and-bevy) - game based on the classical Pikachu Volleyball implemented with Bevy. Instead of Pikachu characters, two cats are playing a volleyball.
* [Connect4](connect-4-simple-with-rust) - Connect4 game played in a terminal
* [Minesweeper](minesweeper-with-rust-and-macroquad) - classical Windows game Minesweeper implemented with Macroquad
* [Pong (Bevy)](pong-with-rust-and-bevy) - classical game Pong implemented with Bevy
* [Pong (Ggez)](pong-with-rust-and-ggez) - classical game Pong implemented with Ggez
* [Space Invaders (simple)](space-invaders-simple-with-rust) - classical Space Invaders game implemented for a terminal
* [Space Invaders (Bevy)](space-invaders-with-rust-and-bevy) - classical Space Invaders game implemented with Bevy

### Java
* [Pong](pong-with-javafx) - classical game Pong
