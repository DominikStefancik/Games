# Duck Hunt with Typescript and Kaplay

An implementation of Duck Hunt based on the classical Nintendo game with the same name with Typescript and the game engine [Kaplay](https://github.com/kaplayjs/kaplay).

The goal is to shoot as many ducks as possible while they are flying. The game is enriched with sound effects and background music.
